# Holdfast Bay Council Organisation Traffic Analysis (Power BI)

## Overview

This project is an end-to-end data analytics workflow for organisations listed in the Holdfast Bay Council area. Data were downloaded from **Google Analytics**, **CiviCRM**, and the **SAcommunity organisation database**, then cleaned, transformed, and integrated using Python before being visualised in **Power BI**.

The project includes both a **2025–2026 annual report** and a **four-year comparative analysis (2023–2026)** of website traffic metrics, including **sessions** and **page views**. Interactive dashboards were developed to monitor user engagement, identify trends over time, and support evidence-based decision-making. The project demonstrates practical skills in data extraction, data cleaning, data integration, data modelling, and dashboard creation.
## Objectives

1. Develop an interactive Power BI dashboard to analyse website traffic for organisations listed in the Holdfast Bay Council area.
2. Produce a **2025–2026 annual report** summarising key website traffic metrics, including sessions and page views.
3. Compare website traffic trends across **four years (2023–2026)** to identify changes in user engagement.
4. Integrate data from Google Analytics, CiviCRM, and the SAcommunity organisation database into a unified reporting dataset.
5. Perform data extraction, cleaning, transformation, and visualisation techniques to support reliable and insightful reporting.
